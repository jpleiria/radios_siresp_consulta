# Consulta Rádios SIRESP — CBSLeiria

Página GitHub Pages protegida por password para consulta da última listagem SIRESP publicada pela aplicação de gestão.

Antes de publicar, preencha `firebase-config.js` com o mesmo projeto Firebase utilizado pela gestão e com o email da conta de consulta. A password nunca deve ser colocada nos ficheiros.

Consulte o guia existente no pacote da aplicação de gestão para configurar Firebase Authentication, Firestore, regras e os dois repositórios.
